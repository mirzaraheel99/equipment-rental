# ERMS Documentation Repository

This folder organizes the generated planning documents. Start with `00-Foundation/MASTER-INDEX.md` for a full inventory of what exists, its status, and known gaps.

## Structure

- `00-Foundation/` — governance registers: master index, decisions, assumptions, open questions, glossary, SRS reconciliation, changelog
- `01-Market-Research/` — Saudi/GCC market and competitive analysis
- `04-Domain/` — domain specifications (Asset Registry, Customer, Contract, Pricing, Rental Operations, Maintenance/PPM)
- `06-Data/` — enterprise database dictionary
- `08-UX/` — screen inventory, navigation, and UI design system
- `09-Implementation/` — roadmap and implementation packs
- `10-References/` — external reference library
